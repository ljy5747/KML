# KML · 국균연구소 웹

왕사슴벌레 계보 및 성충·교배 라인 관리. Google OAuth + 승인 계정 목록 + Supabase RLS.

## BeetleLog 연결 및 선택 가져오기 (2026-10-23)

KML 웹과 BeetleLog 앱은 **같은 KML 성충·라인 테이블**을 조회하고 기록합니다.

- KML 웹: 로그인 → MY PAGE → **성충 관리 또는 라인 관리** → **BeetleLog 가져오기** → 성충·라인에서 항목 체크 → 선택한 기록 가져오기
- BeetleLog 앱: 같은 Google 계정으로 로그인 → 설정 → **국균연구소 KML 연동** → KML 성충·라인 열기
- 한쪽에서 신규 성충·라인을 등록하면 상대쪽 KML 목록을 다시 열거나 새로고침하여 조회할 수 있습니다.
- 기존 BeetleLog `beetlelog_data` JSON(여러 종의 개인 사육기록)은 **변경하지 않았습니다**.
- 연결된 BeetleLog 원본은 자동으로 불러와 선택 목록에 표시하지만, **선택한 기록만** KML에 추가합니다.
- 라인을 선택하면 필요한 부모 성충을 자동으로 가져오며, 기존에 가져온 원본 ID 및 관리번호·라인명 중복을 검사합니다.
- 종명과 기본 혈통·체장·우화일을 반영합니다. 원본의 더 상세한 기록과 사진은 BeetleLog에 그대로 남습니다.
- KML 데이터 센터에서 본인 BeetleLog Google 계정 레코드에 대한 **읽기 전용 연결 확인**도 할 수 있습니다.

**아직 미구현:** 개인 탭과 KML 탭의 자동 병합·변경사항 양방향 실시간 동기화, 병갈이 기록 이전/동기화, KML 엑셀 업로드. 이번 기능은 **일회성 선택 복사**이며 원본 BeetleLog 데이터는 수정하지 않습니다. 단순 KML 공동 목록의 양방향 등록·조회와 혼동하지 마세요.

## 파일 구조

- `docs/SETUP.md`: 승인 계정/Google OAuth 설정
- `docs/SCHEMA_REFERENCE.sql`: 초기 DB 구조 참고
- 기존 `battle/` 페이지 유지

## 보안

승인된 Google 계정만 KML 정보를 조회할 수 있도록 RLS로 제한했습니다. 일반 브리더는 자신이 소유하는 성충과 자신이 생성한 라인을 편집하고, 전체 브리더 명단은 관리자만 조회할 수 있습니다. 일반 브리더에게 필요한 작성자/소유자 닉네임은 제한된 조회를 사용합니다. 웹 소스는 공개되지만 DB가 공개되는 것은 아닙니다.
