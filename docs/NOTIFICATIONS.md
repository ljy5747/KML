# 알림함 · 성충 보내기 · 댓글 좋아요

## 화면

우측 상단 닉네임 옆 종은 읽지 않은 알림 수를 표시합니다(100개 이상 `99+`). 눌러 최근 알림을 보고, 전체 알림 화면에서 이전 알림을 30개씩 더 불러옵니다. 읽음 처리해도 기록은 남습니다. 모두 읽음과 개별 읽음 처리를 지원합니다. 활성 앱에서 약 8초마다 새 알림·좋아요 수를 조회하며 편집창, 댓글 초안, 열린 알림함을 다시 그려 입력이나 스크롤을 버리지 않습니다. 이 기능은 KML 앱 내 알림함입니다.

알림의 브리더 이름·사진은 브리더 목록으로, 본문은 해당 성충 또는 댓글 위치로 이동합니다. 삭제된 성충·댓글의 알림은 이력으로 남고 유효하지 않은 받기 버튼은 표시하지 않습니다.

## 보내기

1. 현재 소유자 또는 관리자가 성충 상세의 **성충 보내기**에서 받을 승인 회원·이동일·메모를 선택합니다. 상대는 KML에 로그인해 프로필을 만든 활성 회원이어야 합니다.
2. 요청을 만들고 받는 회원의 알림함에 적재합니다. 이 단계에서 소유권을 변경하지 않습니다. 성충당 하나의 대기 요청만 허용합니다.
3. 받는 회원이 수락하면 같은 개체의 `owner_id`를 변경하고 상태를 `보유`로 설정합니다. 발신자의 KML 보유 목록에서 빠지고 수신자의 보유 목록에 들어갑니다. 관리번호·부모·브리더·계통과 기존 라인 연결은 유지하며 이동 이력을 한 번만 저장합니다.
4. 받는 회원은 거절, 보낸 회원은 수락 전 취소할 수 있습니다. 발신자는 수락·거절 알림을 받고, 수신자는 취소·만료 알림을 받습니다. 성충의 소유자나 사망 상태가 달라지면 대기 요청을 만료시킵니다.

요청 생성은 성충 버전을 확인합니다. 처리 시 성충→요청 순서로 행을 잠그고 권한과 현재 소유자를 다시 확인합니다. 중복 수락은 추가 이동 이력을 만들지 않습니다. 기존 즉시 소유자 변경 RPC도 수락 요청을 만드는 방식으로 변경해 우회하지 못하게 했습니다. BeetleLog의 개인 계정 자체나 라인·유충의 등록자를 다른 사람에게 복사하는 기능은 아닙니다.

## 댓글과 좋아요

- 새 댓글은 해당 성충의 현재 보유자·브리더에게 알립니다. 같은 사람이면 한 번만 보내며, 작성자 본인에게는 알리지 않습니다.
- 댓글 옆 좋아요는 한 회원당 한 번이며 다시 누르면 취소합니다. 좋아요 수와 내 선택 상태를 표시하고 댓글 작성자에게 알립니다.
- 본인 댓글의 좋아요는 카운트에 포함하되 본인 알림은 만들지 않습니다. 취소 후 재좋아요도 같은 댓글·회원 조합의 알림을 중복 생성하지 않습니다.

## 데이터와 권한

`docs/notifications-transfers.sql`은 프로젝트 소유자로 한 번 적용하는 설치 SQL입니다. `kml_notifications`, `kml_transfer_requests`, `kml_comment_likes` 모두 RLS를 적용합니다. 알림은 본인 수신분만, 보내기 요청은 발신·수신·처음 요청한 당사자만 조회합니다. 클라이언트는 알림 내용·수신자나 요청 상태·대상을 직접 바꿀 수 없습니다. 변경은 권한을 검사하는 비공개 핸들러와 트리거에서 처리하고 공개 RPC는 invoker 래퍼만 둡니다.

닉네임·사진만 제공하는 승인 회원 선택 목록을 사용하며 이메일이나 인증 정보는 반환하지 않습니다. 페이지 커서는 생성 시각과 ID를 함께 사용합니다. 수신자별 목록·미열람·요청 상태, 외래 키와 좋아요 집계에 인덱스를 둡니다.

## 파일과 검증

- `src/features/notifications.js`: 별도 상태, 알림 패널/전체 화면, 받기·보내기, 댓글 좋아요와 갱신
- `src/styles/notifications.css`: 종·배지, 모바일 알림 패널과 목록
- `tests/notifications-ui.cjs`: 배지, 역할별 버튼, 알림 이스케이프, 페이지 유지, 읽음, 좋아요, 계정 변경 응답 폐기
- `tests/notifications-transfers.sql`: 실제 DB에서 임시 회원·성충을 만들고 인증/RLS를 적용하여 보내기·수락·거절·취소·댓글·좋아요·비공개 알림·중복 방지·페이지 이동을 검증한 뒤 전부 롤백

기존 가져오기·연도·계통도·라벨·유충 편집 검사를 함께 통과했습니다. 아이폰/안드로이드 실기기에서 직접 터치한 검증은 포함하지 않습니다.
