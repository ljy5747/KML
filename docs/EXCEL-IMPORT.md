# Excel 가져오기

내 성충 관리·내 라인 관리의 상단에 **Excel 가져오기**를 추가했습니다. 라인 수정 창 안에서도 해당 라인의 유충 파일을 넣을 수 있습니다. 라인 수정 초안은 파일 창을 닫거나 저장한 뒤 복원하며, 파일 저장은 라인 초안을 저장하지 않습니다.

## 양식

- `assets/templates/KML_adults_template.xlsx`: 성충 시트. 신규는 관리번호·혈통·성별 필수. 보유자는 로그인한 본인입니다. 브리더·부모·누대수·상태·입수 경로·우화 정보 등을 함께 입력합니다.
- `assets/templates/KML_larvae_template.xlsx`: 유충 시트. 먼저 등록한 내 라인에 번호별 유충과 병별 기록·용화·우화 정보를 넣습니다. 기본 양식은 5병이며 같은 이름 규칙으로 60병까지 열을 확장할 수 있습니다.
- 두 양식의 예시·안내 시트는 가져오기에서 제외합니다. 번호는 문자열, 날짜는 실제 날짜 값과 yyyy-mm-dd 형식, 무게·체장 등은 숫자로 작성했습니다. 첫 행 제목과 2행 고정 예시·식별 열을 고정했습니다. 2행은 시트 보호로 수정·삭제를 막고 3행부터 500개체를 입력합니다. 고정 예시는 가져오기에서 자동 제외합니다. 입력 열은 502행 아래에서도 편집할 수 있습니다.
- 기존 CSV 내보내기 파일도 UTF-8로 다시 가져올 수 있습니다. 첫 행의 라인명, 빈 행 뒤 관리번호 헤더를 인식합니다. 앞자리 0은 유지합니다.

XLSX·XLS·UTF-8 CSV를 지원합니다. 파일 5MB, 한 번에 500개체, 읽기 30초 제한입니다. 수식과 엑셀 오류 셀은 거부하며 계산 결과를 값으로 붙여넣도록 안내합니다. 알 수 없는 입력 열이나 중복 열·관리번호도 오류로 표시합니다.

## 미리보기와 저장

기존 개체는 기본적으로 건너뜁니다. **기존 개체도 수정**을 체크하면 관리번호(유충은 라인+번호)로 맞춰 변경 항목을 미리 보여주며 변경값 보기를 펼쳐 실제 값을 확인합니다. 빈칸은 기존 값 유지이며 `[비우기]`는 선택 항목만 비웁니다. 번호·소유자를 엑셀로 바꾸거나 다른 회원의 개체를 수정하지 않습니다.

새로운 라인 생성은 기존 라인 생성 화면을 사용합니다. 신규 파일 기록은 KML에 등록됩니다. 이미 연결된 성충·유충 수정은 기존 DB 트리거를 통해 BeetleLog 원본에도 반영됩니다. 사진·플래그·입력하지 않은 병별 메타데이터는 DB에서 병 ID·순서와 함께 보존합니다.

`docs/excel-import.sql`의 invoker RPC는 전체 파일을 한 트랜잭션으로 저장합니다. 기존 버전과 소유 권한을 다시 확인하며, 한 행이라도 실패하면 KML·연결된 BeetleLog 변경을 모두 롤백합니다. 신규 부모를 같은 파일에서 먼저 참조할 수 있도록 성충 생성 후 부모 연결을 처리하고, 순환을 거부합니다. 소유자·연동 ID·사진 등의 변경은 허용 목록에 없습니다.

## 읽기와 성능

`assets/excel-worker.js`는 파일 선택 시에만 실행하며 `assets/vendor/xlsx-0.20.3.full.min.js`를 불러옵니다. 홈에서는 엑셀 파서를 내려받지 않습니다. 시트 보호는 Artifact Tool 내보내기 뒤 표준 OOXML 보호·잠금 스타일만 추가합니다(`scripts/protect-excel-templates.py`). SheetJS CE 0.20.3은 공식 CDN에서 가져온 고정 버전이며 Apache-2.0 라이선스를 함께 보관합니다. 파일은 브라우저에서 읽고, 저장을 누르면 검증된 변경 항목만 RPC로 전송합니다.

양식은 `scripts/build-excel-templates.mjs`에서 Artifact Tool로 생성했습니다. 재생성은 Codex 기본 런타임 Node와 Artifact Tool 의존성을 사용하는 스크립트를 복사한 임시 디렉터리에서 실행하고 출력 디렉터리를 인자로 지정합니다. 미리보기 PNG와 검사 중간 파일은 사이트에 배포하지 않습니다.

## 검증

- `node tests/excel-import-ui.cjs`: 실제 XLSX 양식과 CSV 읽기, 예시·안내 제외, 001·0·날짜 보존, 옵트인 수정, 빈칸·비우기, 부모 연결·순환, 권한, 중복·수식 오류, 업로드 UI
- `tests/excel-import-db.sql`: 실제 인증·RLS 환경에서 신규·수정, 부모 참조, 사진·메타데이터·0 보존, 원본 동기화, 충돌·권한 거부, 전체 롤백을 검사 후 임시 변경을 모두 롤백

기존 연도·계통도·라벨·알림·유충 편집 회귀 검사도 함께 확인합니다. 모바일 실기기 파일 선택과 Excel 데스크톱 애플리케이션에서의 직접 조작은 별도 검증 대상입니다.
